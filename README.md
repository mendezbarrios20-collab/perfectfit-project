# PerfectFit Bowl

PerfectFit Bowl es un emprendimiento digital de alimentación saludable en Cartagena y el proyecto final desarrollado para el programa **Jóvenes CreaTIvos 2026**. La aplicación reúne un catálogo de platos funcionales, herramientas de gestión y orientación nutricional en una experiencia web.

## Funcionalidades

- **Landing Page:** presenta la marca, sus objetivos y productos destacados.
- **Catálogo dinámico:** muestra platos organizados por categoría, permite filtrar opciones y agregarlas al carrito.
- **Contacto:** recibe consultas y pedidos mediante un formulario que guarda los mensajes en la base de datos.
- **Panel de administración:** requiere iniciar sesión y tener rol de administrador. Permite crear, consultar, actualizar y eliminar platos, además de gestionar mensajes.
- **Coach Nutricional con IA:** utiliza Google Gemini y consulta el menú actualizado para orientar sobre los productos disponibles.

## Tecnologías

- **Frontend:** React 19, Vite, JavaScript y Fetch nativo.
- **Backend:** Node.js y Express 5.
- **Datos:** MongoDB Atlas con Mongoose.
- **Asistente de IA:** Google Gemini.
